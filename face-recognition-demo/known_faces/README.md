# 已知人脸目录

把照片放在这个目录里，**一张照片 = 一个人，文件名就是显示的人名**。

例如：
- `me.jpg`      -> 画面里认出来时显示 "me"
- `张三.jpg`     -> 显示 "张三"
- `李四.png`     -> 显示 "李四"

程序启动时会自动读取本目录下的所有图片（jpg / jpeg / png / bmp / webp），
其中 `me.jpg` 会被优先加载（对应 config.py 里的 DEFAULT_IMAGE）。

推荐的照片要求：
- 正脸、五官清晰、光线充足，不要逆光
- 脸在照片里要够大（别用大合影，程序只会取照片里最大的一张脸）
- 不要戴墨镜/口罩，避免严重侧脸

怎么把照片放进来？三种办法：
1. 直接把照片改名为 me.jpg 放进本目录
2. 用录入助手现场拍照：`python enroll.py --name 张三`
3. 从已有图片导入：`python enroll.py --from D:\照片\自拍.jpg --name 张三`

查看当前已录入的人：`python enroll.py --list`

> 提示：本目录里的照片属于个人敏感信息。分享/上传代码前请先删除它们，
> 或者把 .gitignore 里 `known_faces/` 那一行的注释打开。
